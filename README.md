# ВнучОК — платформа заботы о пожилых людях

MVP-платформа по техническому заданию: пожилой человек простым голосом или крупными
кнопками запрашивает продукты, аптеку, звонок или помощь; родственник получает
семейный кабинет с уведомлениями, отчётами и подпиской; оператор обрабатывает
заявки, звонки и тревожные эскалации в админ-панели.

**ВнучОК не продаёт доставку. ВнучОК продаёт спокойствие семьи.**

## Состав

| Часть | Технологии | Описание |
|---|---|---|
| `backend/` | Python, FastAPI, SQLAlchemy, SQLite (PostgreSQL-ready) | REST API: auth (SMS-код / код подключения / пароль), заявки, голосовой контур, check-in, подписки и платежи, уведомления, операторская панель, аналитика, аудит, RBAC, rate limiting |
| `frontend/` | React, Vite, PWA | Три интерфейса в одном приложении: пожилой пользователь, кабинет родственника, админка оператора. Устанавливается на телефон как приложение (PWA = мобильная версия) |

## Быстрый старт (локально)

```bash
# Бэкенд
cd backend
pip install -r requirements.txt
uvicorn app.main:app --port 8000        # http://localhost:8000/docs — Swagger

# Фронтенд (в другом терминале)
cd frontend
npm install
npm run dev                              # http://localhost:5173
```

Или одной командой через Docker:

```bash
docker compose up --build                # фронт на :8080, API на :8000
```

## Демо-доступы (создаются автоматически)

| Роль | Вход |
|---|---|
| Пожилой пользователь | вкладка «Я пожилой человек», код подключения `DEMO01` |
| Родственник | вкладка «Я родственник», телефон `+79991234567`, SMS-код `1234` (демо-режим) |
| Оператор | вкладка «Сотрудник», `+70000000002` / `operator123` |
| Администратор | вкладка «Сотрудник», `+70000000001` / `admin123` |
| Партнёр (Магнит Доставка) | вкладка «Сотрудник», `+70000000003` / `partner123` |

Демо-промокоды: `ZABOTA10` (−10%), `PILOT50` (−50%, 30 использований).

В демо-режиме (`VNUCHOK_DEMO_MODE=1`) SMS-код не отправляется, а возвращается в ответе
API и показывается на экране.

## Ключевые сценарии MVP (раздел 29 ТЗ)

1. **Регистрация родственника** по телефону с подтверждением кодом, согласие на ПДн.
2. **Добавление пожилого** — родственник создаёт профиль и получает код подключения;
   пожилой входит по коду без регистрации.
3. **Экран пожилого**: 6 крупных кнопок (Продукты, Лекарства, Позвонить, Повторить
   заказ, «Мне нужна помощь», «Всё хорошо») + голосовой ввод. Шрифт ≥20pt, кнопки
   ≥96px, голосовое сопровождение (TTS), один экран — одно действие, подтверждение
   важных действий.
4. **Голосовая заявка**: речь распознаётся Web Speech API (на устройстве), текст
   классифицируется AI-агентом (категория, срочность, уточнение). Архитектура
   позволяет заменить rule-based классификатор на LLM/Yandex SpeechKit.
5. **Safety-слой AI**: тревожные маркеры («плохо», «упал», «сердце»…) ⇒ немедленная
   тревожная эскалация оператору и уведомление родственнику. AI не ставит диагнозы
   и не даёт медицинских рекомендаций — человек всегда в контуре.
6. **Check-in**: кнопка «Всё хорошо», расписания, статус активности на дашборде
   родственника (всё хорошо / требуется внимание / давно нет связи / тревога).
7. **Оператор**: дашборд (тревоги, новые, просроченные, без связи), карточка заявки
   с распознанным голосом и AI-классификацией, статусы по ТЗ, назначение партнёра,
   комментарии родственнику, журнал звонков со скрипт-результатами и автоотчётом.
8. **Партнёры**: справочник (ритейл, аптека, клиника, бытовые, НКО, волонтёры),
   передача заявки партнёру, в MVP — ручная диспетчеризация оператором.
9. **Подписки**: тарифы «На связи» 990₽, «Забота» 2490₽, «Рядом» 4990₽ +
   бесплатный социальный контур через НКО. Мок платёжного провайдера
   (заменяется на ЮKassa/CloudPayments), история платежей, чеки, автопродление.
10. **Уведомления**: лента в приложении с бейджем непрочитанных (каналы SMS/Push/
    Telegram подключаются к Notification-сервису).
11. **Аналитика**: регистрации, подключённые пожилые, заявки/выполнение, голосовые
    и повторные заказы, check-in, звонки, тревоги, платящие, MRR.
12. **Безопасность**: JWT (HS256), RBAC по 6 ролям, rate limiting, PBKDF2-хэши
    паролей, audit log всех ключевых действий, согласия на ПДн/голос.

## Функции версии 2 (сверх MVP)

- **Партнёрский кабинет**: партнёр входит по паролю, видит назначенные заказы
  с адресом и комментарием по доступу, принимает в работу, закрывает с
  комментарием — статусы сразу видят оператор и семья. Логины кабинетов
  создаёт администратор на странице «Партнёры».
- **Семейный чат**: общая лента для родственников, подопечного и оператора.
  У пожилого — крупные пузыри и кнопка «🔊 Прочитать вслух» (TTS).
- **Напоминания о лекарствах**: расписание задаёт семья/оператор, пожилой
  отмечает «✅ Принял» на главном экране, семья видит отметки за неделю.
  Платформа не назначает препараты и не советует дозировки.
- **Диалоговый AI**: после распознавания агент переспрашивает («Я понял: вам
  нужны продукты. Верно?») с альтернативами; тревожные запросы уходят
  оператору мгновенно, без подтверждений.
- **Фоновый монитор**: автопометка просроченных заявок (>24 ч) и уведомления
  «давно нет связи» (>48 ч без check-in) родственникам и операторам.
- **Промокоды**: создание в админке, применение при оплате подписки.
- **Аналитика с графиками**: динамика заявок, check-in и тревог за 14 дней
  + выгрузка заявок в CSV для НКО и фондов.
- **Доступность**: переключатель размера шрифта (A/A+/A++) в приложении
  пожилого, приветствие по времени суток, звонки доверенным контактам в
  одно касание (`tel:`).

## Структура API

Swagger доступен на `/docs`. Группы: `/auth`, `/users`, `/requests`, `/voice`,
`/checkins`, `/payments` + `/subscriptions` + `/tariffs`, `/notifications`, `/admin`
(дашборд, заявки, звонки, тревоги, партнёры, аналитика, аудит, лента активности).

## Конфигурация

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `VNUCHOK_SECRET_KEY` | dev-ключ | Подпись JWT — обязательно сменить в проде |
| `VNUCHOK_DATABASE_URL` | `sqlite:///./vnuchok.db` | Для прода: `postgresql+psycopg://…` |
| `VNUCHOK_DEMO_MODE` | `1` | `0` — коды отправляются через SMS-провайдера |
| `VITE_API_URL` | `/api` | База API для фронтенда |

## Что сознательно за рамками MVP (раздел 25 ТЗ)

Собственная доставка, продажа рецептурных лекарств, медицинская диагностика,
видеонаблюдение, маркетплейс сиделок, носимые устройства, интеграция с Яндекс
Станцией — вынесены в версии 2–3.
